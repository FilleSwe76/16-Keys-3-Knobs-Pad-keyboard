# Changelog

## 1.0.0 – 2026-11-22

First release.

- Native Windows settings window with a live keypad picture and seven color themes.
- Actions: volume, brightness (WMI + DDC/CI), focused-app volume, mic mute, media, shortcuts, text, launch, commands, scroll, zoom and lock.
- Programs CH57x keypads: 514C:8850 (0xFD protocol), 1189:8840/8842 and 1189:8890.
- Trigger codes are limited to F13–F24 (+Shift/Ctrl), and every key and knob always gets a unique code.
- Learn mode, layout rotation and Detect layout.
- On-screen display, tray icon, start with Windows, pause.
